# 多环境配置管理

## 一、设计目标

- 一套代码跑遍 dev / test / staging / prod，**切换环境不改一行代码**
- 敏感信息（密码、密钥）**不进代码仓库**
- 配置缺失**启动即报错**，而不是跑到一半才失败
- 个人本机调试**不影响**他人与流水线

---

## 二、三层配置合并

配置来源共三层，按顺序合并，**后者覆盖前者**：

```
default 层（所有环境共享的基础配置）
      ↓ 覆盖
当前环境层（dev / test / staging / prod）
      ↓ 覆盖
local.yaml 本地覆盖层（个人本机调试，不入库）
```

`config/environments.yaml` 结构：

```yaml
default:        # 所有环境共享：浏览器、超时、日志级别、产物目录……
  browser: chrome
  headless: true
  poll_interval: 0.5

test:           # test 环境特有：域名、账号
  base_url: http://test.example.com
  api_base_url: http://test-api.example.com

staging:
  base_url: https://staging.example.com
  common_pwd: "${STAGING_COMMON_PWD}"   # 占位符，从环境变量注入

_meta:          # 框架元信息，不参与业务合并
  required_keys: [base_url, browser]    # 必填校验
  available_envs: [dev, test, staging, prod]
  default_env: test
```

## 三、环境切换

优先级：**命令行 > 环境变量 > local.yaml > 默认环境**

```bash
python run.py -e dev          # 方式1：命令行（推荐）
ENV=dev python run.py         # 方式2：环境变量
python run.py --list-envs     # 查看全部可用环境
```

直接用 pytest 时选项为长选项（pytest 保留了小写短选项）：

```bash
python -m pytest --env dev
```

`local.yaml` 里也可以指定本机默认环境：

```yaml
__env__: dev
```

## 四、本地个人调试

复制 `config/local.yaml.example` 为 `config/local.yaml`（该文件已被 `.gitignore` 忽略），
只写你想在本机覆盖的字段：

```yaml
headless: false            # 本机想看到浏览器执行过程
use_stub_browser: false    # 用真实 Chrome
base_url: http://127.0.0.1:8080   # 连本机起的服务
```

---

## 五、敏感信息注入

配置文件里**不留明文**，一律写 `${环境变量名}`，由框架在读取时替换：

```yaml
prod:
  common_pwd: "${PROD_COMMON_PWD}"
```

```yaml
# config/database.yaml
prod:
  password: "${PROD_DB_PASSWORD}"
```

值从以下位置注入，优先级由 `python-dotenv` 决定（已存在则不覆盖）：

- 本地：`config/.env`（不入库，见 `config/.env.example`）
- CI：平台的加密环境变量（GitLab CI/CD Variables、Jenkins Credentials、GitHub Secrets）

---

## 六、必填校验

`_meta.required_keys` 里的 key 在当前环境（含 default 合并后）缺失时，**启动即抛出明确异常**：

```
ValueError: 环境 'dev' 缺少必填配置项 ['base_url']，
请检查 config/environments.yaml 或 config/local.yaml
```

好处：配置出错在启动阶段暴露，而不是等某个用例执行到一半才报 KeyError。

---

## 七、代码中读取配置

```python
from common.env_manager import config

config.get("base_url")            # 读取（带默认值：config.get("key", default)）
config.current_env                # 当前环境名
config.available_envs             # 全部可用环境
config.exists("readonly")         # 是否存在
config.switch("dev")              # 运行期切换（会重新合并并校验）
config.describe()                 # 一行概览，用于日志
config.load_layered_yaml("database.yaml")   # 读取其它同样分层的配置文件
```

> 全工程只有 `common/env_manager.py` 一个配置入口，避免出现多套配置系统。
